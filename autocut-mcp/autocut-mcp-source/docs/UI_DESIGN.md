# UI 设计规范（本仓库前端重设计的“设计语言”）

> 依据调研整理：Anthropic 官方 `frontend-design` skill、`ibelick/ui-skills`、
> shadcn/ui 语义 token 体系。凡改动 `ui/` 前端都必须遵循本规范。

## 工作方法（写代码前先定设计语言）
1. **定方向**：本产品是“专业剪辑台”类工具 → 采用 **工业/克制的深色剪辑室** 审美，
   强调信息密度与精确时间码，而非营销页。
2. **Token 先行**：所有颜色/圆角/阴影/间距都从下方 token 取，禁止散落字面值。
3. **签名元素**：时间码 + 走带/播放头 + 胶片齿孔意象 = 让人记住的点。
4. **反模式（禁止）**：紫→蓝渐变配白底；纯黑底荧光绿；奶油底衬线陶土红；
   “大数字+小标签+渐变卡”模板；每个 hover 都加散装动画；无意义编号装饰。

## 色彩 Token（hex，深色主题）
| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0a0c11` | 页面底色 |
| `--panel` | `#12151d` | 卡片/面板 |
| `--panel2` | `#181c26` | 内嵌块/输入底 |
| `--line` | `rgba(148,163,184,.14)` | 边框/分隔 |
| `--txt` | `#e9edf5` | 主文字 |
| `--txt2` | `#a7b0c0` | 次级文字 |
| `--muted` | `#626d80` | 弱化/占位 |
| `--acc` | `#ffb340` | 主强调(操作/选中/播放头) |
| `--acc2` | `#ffd58a` | 强调高亮 |
| `--ok` | `#3ddc97` | 成功 |
| `--err` | `#ff5c6c` | 错误 |
| `--info` | `#6aa9ff` | 音频轨/信息 |

## 字体
- 正文/界面：系统中文栈 `-apple-system,"Segoe UI","Microsoft YaHei","PingFang SC",sans-serif`
- 数字/时间码：等宽栈 `ui-monospace,"Cascadia Mono","SF Mono",Consolas,monospace`
- 标题用字重对比（700/800）+ 微量字距，不用花哨外来字体（离线环境不能依赖 webfont）。

## 布局
- 顶部品牌条 + 步骤导航；左侧固定“素材库(Bin)”；右侧按标签切换工作区。
- 时间码一律 `MM:SS.mmm` 风格、等宽呈现；编号仅在有真实顺序时使用。

## 动效
- 只在关键处编排一次：面板淡入、任务进度条推进、toast 滑入。
- 不做散装 hover 弹跳。hover 只改变底色/边框/文字强调。

## 文案
- 按钮说清“点了会发生什么”；错误提示给“哪里错+怎么修”，不道歉；
- 空状态 = 引导下一步动作。
